# Mundo de Blocos
![print](https://github.com/TheBlindMole/Python-Cube-Game/blob/main/Screenshot_1.png?raw=true)

#Um jogo simples em primeira pessoa feito com [Ursina Engine](https://www.ursinaengine.org/)

## O que o jogo faz

- Movimento em primeira pessoa (andar, pular, olhar em volta)
- Plataforma de 16x16 blocos para explorar
- Colocar e destruir blocos com o mouse
- Hotbar com 4 cores diferentes para escolher
- Menu de pausa
- Reposicionamento automático caso você caia da plataforma

## Requisitos

- Python 3.9 ou superior
- Biblioteca Ursina

Instale a dependência com:

```bash
pip install ursina
```

## Como rodar

```bash
python main.py
```

## Controles

| Tecla / Ação        | Função                          |
|---------------------|----------------------------------|
| W A S D              | Mover                            |
| Mouse                | Olhar em volta                   |
| Espaço               | Pular                            |
| 1, 2, 3, 4           | Trocar a cor do bloco selecionado |
| Botão direito do mouse | Colocar bloco                  |
| Botão esquerdo do mouse | Destruir bloco                |
| Esc                  | Pausar / continuar o jogo         |
